Cómo funciona la colaboración

1. Todos trabajan sobre la misma base de datos central: cualquier alta, edición o cambio de estado se guarda en el servidor.

2. Los cambios de otros usuarios aparecen automáticamente en tu pantalla, sin recargar la página.

3. Para dar acceso a un colega, simplemente compartile el link de la aplicación.

4. Exportar sirve como respaldo o para llevar los datos a otra herramienta; Importar permite cargar un respaldo (Reemplazar todo) o sumar iniciativas de un archivo (Agregar como nuevas).

La persistencia es central en el servidor; el archivo JSON es un mecanismo de respaldo, no de colaboración.
